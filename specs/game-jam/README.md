# Game Jam — índice de specs

Cada game jam recibe un tema y produce **un** juego nuevo con tres specs completos
(`spec.md`, `design.md`, `engine.md`) en `specs/game-jam/<game-id>/`.

Todos los specs de esta carpeta nacen en estado `Draft`: hay que revisarlos antes de
implementarlos con `/spec-impl`.
